## 开场白
老师好，我是杨博宇。今天向您汇报我的毕业设计题目——《基于Spring Boot的校园招聘系统》。
该系统旨在解决高校毕业生与企业之间信息不对称的问题，通过数字化手段实现招聘流程的全周期管理。
下面我将从**数据库设计**、**项目架构**、**核心功能**以及**系统亮点**四个方面进行详细介绍。

## 1. 数据库结构说明
“首先汇报一下数据库的设计思路。为了支撑整个招聘业务，我设计了 **13张数据表**，逻辑上可以分为三个核心板块：”

*   **第一板块是“用户中心”**：
    *   以 `sys_user` 表为核心，统一管理管理员、学生和企业三种角色。
    *   然后通过 `student_profile`（学生档案表）和 `company_profile`（企业档案表）进行扩展，分别存储学生的学历、技能信息以及企业的行业、规模等详细资料。
*   **第二板块是“招聘业务流”**：这是系统的骨架。
    *   从 `job`（职位表）发布开始，关联到 `resume`（简历表）。
    *   两者结合生成 `application`（投递申请表）。
    *   随后业务流转到 `interview`（面试记录表）和 `offer`（录用通知表）。
    *   每一步操作都有迹可循，构建了一个闭环。
*   **第三板块是“辅助支撑”**：
    *   包括 `job_fair`（招聘会）、`message`（消息通知）和 `operation_log`（操作日志），用于提升用户体验和系统安全性。

---

## 2. 项目结构（分层说明）
“接下来介绍项目的整体架构。本项目采用了目前主流的**前后端分离**开发模式，结构清晰，易于维护。”

*   **后端技术栈**：
    *   我基于 **Spring Boot 2.7** 搭建，采用了经典的分层架构设计：
    *   最外层是 **Web层 (Controller)**：负责接收前端请求和参数校验，处理HTTP交互。
    *   中间是 **业务层 (Service)**：这是系统的“大脑”，封装了所有的业务逻辑，比如投递简历时的状态流转判断、权限校验等。
    *   底层是 **持久层 (Mapper)**：使用 **MyBatis-Plus**，极大简化了SQL的编写，提高了开发效率。
*   **前端技术栈**：
    *   采用了 **Vue 3** 配合 **Ant Design Vue** 组件库，状态管理使用了最新的 **Pinia**。这种组合保证了界面的美观度和操作的流畅性。

---

## 3. 核心模块功能及技术细节
“系统主要包含以下几个核心功能模块：”

1.  **职位与企业管理模块**：
    *   企业可以发布、管理职位，系统会自动关联企业的审核状态。
    *   **技术细节**：这里用到了 **MyBatis-Plus的分页插件** 和 **动态SQL**，实现了多条件组合查询（如按城市、薪资、学历筛选），响应速度非常快。

2.  **全流程招聘模块**（最核心）：
    *   实现了从 **简历投递 -> 面试邀约 -> 录用发放** 的完整流程。
    *   **技术细节**：为了保证数据的一致性，我在关键业务节点（如撤回申请、发送Offer）使用了 **Spring事务管理 (@Transactional)**。同时，配合 `message` 表，每当状态变更时，系统会自动触发一条站内信通知，提醒用户及时处理。

3.  **安全认证模块**：
    *   **技术细节**：使用了 **Spring Security + JWT** 的组合。用户登录成功后生成Token，前端将其存储在Header中。后端通过拦截器验证Token的合法性和有效期，实现了无状态的身份认证，有效防止了未授权访问。

## 4. 项目亮点（重点介绍）
“最后，我想重点介绍一下本项目的两个创新亮点，这也是我在设计时着重考虑的**智能化**体验。”

### (1) 智能推送算法 (Intelligent Push)
“为了解决传统招聘网站‘海量职位难筛选’的痛点，我设计了一套**基于内容的推荐算法**。”
*   **实现逻辑**：
    *   系统会提取学生简历中的关键标签，比如“求职意向”、“技能特长”（如Java、Python）以及“期望城市”。
    *   将这些特征与职位表中的“任职要求”和“工作地点”进行**加权匹配**。
    *   例如，技能匹配度占40%，地域匹配度占30%，学历要求占30%。
    *   通过算法计算出一个`match_score`，分数越高的职位，会优先在学生的首页进行展示。
*   **价值**：实现了从“人找职位”到“职位找人”的转变，大大提高了投递的成功率。

### (2) AI大模型赋能 (AI Integration)
“紧跟当前AIGC的技术热点，我也尝试将大模型能力融入到系统中。”
*   **应用场景一：智能简历优化**
    *   学生上传简历内容后，系统可以调用大模型API，对自我评价和项目经历进行润色，使其更符合HR的阅读习惯。
*   **应用场景二：JD（职位描述）自动生成**
    *   企业HR在发布职位时，往往不知道怎么写职位描述。
    *   现在只需输入“Java后端”、“3年经验”、“熟悉Spring Boot”这几个关键词，系统就能自动通过AI生成一段结构清晰、语气专业的职位描述，极大地提升了企业的发布效率。
